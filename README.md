# Josep Rodon — Portfolio

Personal portfolio website. Built as a static site using HTML, CSS, and React (loaded via CDN with in-browser Babel transpilation).

## Local development

Open `index.html` in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deployment

Deployed automatically to Vercel on push to `main`.
